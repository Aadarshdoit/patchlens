# IBM Bob 2.0 Usage

PatchLens was developed using IBM Bob 2.0 as the primary AI-assisted development environment.

The Bob sessions documented in this folder show the development process across:

- Frontend initialization and interface development
- Backend verification engine development
- Benchmark and validation work
- Security hardening
- Project upload workflow
- Final UI and engineering polish

Bob was used to accelerate implementation, debugging, code review, testing, and iterative refinement.

The final verification verdicts are produced by PatchLens's deterministic execution and evidence-based verification engine. Bob is a development tool for building PatchLens, not the runtime decision-maker.
